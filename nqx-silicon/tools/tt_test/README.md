# NQX-S1 for Tiny Tapeout

Generated by `tools/export_tinytapeout.py`. Do not edit here; change the
RTL in `../rtl` and re-export.

- Build: DIM = 32, iterative CORDIC. Bit-exact with `../model` at DIM = 32.
- Area: 0.38 mm² of GF180MCU cells, synthesis estimate. `info.yaml` asks
  for 4×4 tiles (1386 × 643 µm, about 42 % utilization).
- Test: `cd test && make` (Icarus + cocotb) runs the identity and
  encode/decode tests against the model.

## Submitting

1. Create a repository from Tiny Tapeout's template for the target shuttle
   (`ttgf-verilog-template` for GF180MCU, `ttihp-verilog-template` for IHP).
2. Copy `info.yaml`, `src/`, `docs/` and `test/` from this directory over the
   template files.
3. Push. The template's GitHub Actions build the GDS (`gds`), run the
   precheck and the gate-level test (`gl_test`).
4. Submit the repository at app.tinytapeout.com before the shuttle deadline
   (TTGF26c: 2026-12-07 20:00 UTC).

For an IHP shuttle, re-export with `--tiles 8x2`; the IHP cell area is
0.22 mm². Also change the GL cell-library paths in `test/Makefile` to the
IHP ones.
