# NQX-S1 — Design for test and production test

**Document status:** preliminary. Revision 1.0, 2026-09-24.

## 1. Strategy

NQX-S1 uses **functional test through the command interface**. It has no
scan chains and no memory BIST. This is the usual choice for MPW test chips:

- The open-source flow (LibreLane 3.0.14) has no scan-insertion step, and
  none of the target MPW services (IHP, wafer.space, Tiny Tapeout) requires
  scan.
- The design is small (5 633 flip-flops) and highly observable. Every
  architectural state bit can be written and read back through LDV/STVR/CSR
  commands. The datapaths are exercised by ENC/DEC with known answers from
  the bit-accurate model.
- All flip-flops reset asynchronously, so every test starts from a known
  state without initialization sequences.

For a production part (NQX-S2 and later), scan insertion (OpenROAD
`insert_dft` or a commercial tool) and ATPG are required; see §5.

## 2. Observability and controllability map

| Block | Flip-flops | Control | Observe | Test file |
|---|---|---|---|---|
| Vector register | 3 072 | LDV (16 of 24 bits per word directly); rotations and DEQUANT reach the fraction and extension bits | STVR (all 24 bits) | `01_vector_register`, `02_rotation` |
| CORDIC pipeline (input stage + 18 iterations + output stage) | 1 832 | GVNS/POLAR/IPOLAR with chosen vectors and INC values | Results in VR via STVR | `02_rotation`, `03_polar`, `06_programmable_rotation` |
| Quantizer registers, RMIN/RMAX, performance counters | ≈ 270 | QUANT after POLAR | Packet bytes, RMIN/RMAX CSRs | `03_polar`, `04_encode_decode` |
| Dequantizer header, divider | ≈ 130 | DEQUANT/DEC with random packets, REFINE on and off | VR via STVR/STV | `04_encode_decode`, `05_refine_off` |
| Sequencer, CSRs, phase accumulator and increments | ≈ 300 | CSRW | CSRR | `00_identity`, `06_programmable_rotation` |
| Status, error paths | 2 | Illegal commands, saturating packets | STATUS | `07_errors` |
| Handshake bridge, reset synchronizer | ≈ 30 | Every byte | Every byte | all |
| Everything, randomized | — | Random command programs | Output stream | `08_random_programs` |

## 3. Test vectors

`vectors/*.txt` is generated by `tools/gen_vectors.py` from the
bit-accurate model. `vectors/MANIFEST.txt` records a SHA-256 of each file.

```
W 010000...        host writes these bytes
R 3158514e...      chip must answer exactly these bytes
.                  end of transaction
```

- Each file starts from reset. Expected data never includes timing-dependent
  counters, so a pass is an exact byte comparison.
- Before release, every file is replayed through the pins of the RTL and of
  the gate-level netlist (`verif/cocotb/test_top.py::golden_vectors`).
- The host runner (`host/run_all_vectors.py`) runs the same files on a
  microcontroller connected to the chip ([`10_bringup.md`](10_bringup.md)).

| File | Transactions | Bytes written | Purpose |
|---|---|---|---|
| `00_identity` | 2 | 31 | ID, version, parameters, reset values, scratch, SYNC |
| `01_vector_register` | 9 | 2 331 | March-style patterns: 0, −1, 0x5555, 0xAAAA, checkerboards, walking ones, ramp |
| `02_rotation` | 8 | 2 208 | Each layer forward/inverse with full readback |
| `03_polar` | 9 | 2 421 | Vectoring, RMIN/RMAX, inverse polar |
| `04_encode_decode` | 39 | 12 792 | Edge, KV-like and full-scale vectors, ENC + DEC |
| `05_refine_off` | 8 | 440 | Decoder with residual refinement disabled |
| `06_programmable_rotation` | 4 | 1 623 | Non-default and extreme INC values |
| `07_errors` | 6 | 100 | Illegal commands, saturation, W1C |
| `08_random_programs` | 6 | 14 116 | Constrained-random command mixes |

## 4. Test flow for fabricated dies

1. **Continuity and power.** Measure IOVDD and VDD supply current at reset
   (rst_n low, clock stopped), then with the clock running at 1 MHz. Compare
   with the estimate in [`06_physical_design.md`](06_physical_design.md);
   reject dies above 3× the median.
2. **Identity.** Replay `00_identity` at 1 MHz.
3. **Full functional test.** Replay files 01…08 at 10 MHz and at the target
   50 MHz.
4. **Margining** (a characterization sample, not every die). Sweep VDD from
   1.08 to 1.32 V and the clock up to failure; record the frequency limit.
5. **Asynchronous stress.** Run `04_encode_decode` with the host toggling at
   random intervals relative to the chip clock (≥ 10⁶ transactions) to
   exercise the synchronizers.

Pass/fail: all bytes equal. Any mismatch is a fail. The first mismatching
transaction number tells which block to suspect (table in §2).

## 5. Toward production DFT (NQX-S2)

| Item | Recommendation |
|---|---|
| Scan | Mux-D scan on all flip-flops, 8–16 chains, test clock through the clk pad, scan_enable/test_mode pins or a JTAG TAP (`nqx-core/nqx/jtag.py` models one) |
| ATPG | Stuck-at ≥ 99 %, transition ≥ 90 % |
| Memory BIST | March C− for SRAM banks once the vector register moves to SRAM |
| Boundary scan | IEEE 1149.1 if the part goes on a multi-chip board |
| IDDQ | Supported by the all-reset, no-clock-gating design |
